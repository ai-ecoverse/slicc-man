# slicc-man

`@ai-ecoverse/slicc-man`: `man`, `apropos` and `whatis` for SLICC, and `scman` for SLICC and hosts, rendering the Markdown pages of www.sliccy.com/man itself (no host man, groff or mandoc). README.md is the spec. No comments in any file. No CLAUDE.md, no `.md` besides README.md and AGENTS.md. Unit tests live in the gitignored `test/unit/` (`npm run test:unit` writes coverage to `coverage/unit/lcov.info`; the pre-commit hook wants 100% of changed lines); committed tests in `test/integration/`. Tests use a local HTTP server on an ephemeral port for the site (`SLICC_MAN_URL`), a temporary cache and fake tools on `PATH`; only CI touches the real site. CI is `ci.yml` on slicc-shared-web's pipeline, Linux only. `npm run lint` and `npm test` must pass. Never use ports 9222-9229. Releases come from `main` via semantic-release; never move or delete a pushed tag.
